# AI Production AP

**AI Production AP** — מערכת הפקה אישית לסרטוני AI: Pipeline מסודר מהבריף ועד הסרטון הסופי, עם **Human-in-the-loop** —
המערכת מכינה, מפעילה משימות ועוקבת; אתה מאשר בנקודות הבקרה. שום שלב לא מתקדם בלי האישור המתאים.

**טייס אוטומטי מלא:** ChatGPT כותב, Claude מבקר ומשפר, ואחר כך המערכת מייצרת לבד תמונה לכל שוט, הנפשה, קריינות,
מוזיקה וסרטון ערוך — ואתה רק מאשר כל שלב. אישור שלב מפעיל מיד את הבא (העלות המשוערת מוצגת על כפתור האישור).

| שלב | מי עושה | אתה |
| --- | --- | --- |
| 01 אפיון | אתה | ממלא ומסמן "מוכן" |
| 02 תסריט | ChatGPT כותב → Claude מבקר ומשפר ומסביר מה שינה | אישור פנימי + אישור לקוח |
| 03 סטורי בורד | ChatGPT מפרק לשוטים עם פרומפטים → Claude מבקר | מאשר שוטים |
| 04 רפרנסים | לא חובה — רפרנס מאושר משמש כתמונת ייחוס | — |
| 05 תמונות | KIE · Nano Banana (כל השוטים במקביל) | מאשר / "צור מחדש" עם הערה |
| 06 הנפשה | KIE · Kling / Seedance / Hailuo לפי השוט | מאשר / "צור מחדש" |
| 07 סאונד | KIE · ElevenLabs (עברית: v3) + Suno | מאשר |
| 08 עריכה | ffmpeg בשרת: חיבור, חיתוך, קריינות, מוזיקה מונמכת | מאשר |
| 09 מסירה | הורדת הסרטון | מסמן שהלקוח אישר |

שמירה על הכסף: לפני כל שלב בתשלום מוצגת עלות משוערת; יש תקרת תקציב לפרויקט; יצירה שנכשלה לא נוצרת שוב אוטומטית;
ניסיון חוזר אחרי תקלת רשת ממשיך לחכות לאותה משימה ב-KIE ולא משלם שוב.

## הפעלה בענן — כתובת קבועה, בלי להריץ כלום במחשב (מומלץ)

השרת מוכן לפריסה ב-[Render](https://render.com) (קבצים: `Dockerfile`, `render.yaml`). פעם אחת:

1. נרשמים ל-Render ומחברים את חשבון GitHub (ריפו `ohada-tech/general`).
2. **New → Blueprint** → בוחרים את הריפו (ואת הענף שבו נמצא `render.yaml`) → Render קורא את ההגדרות לבד.
3. Render מבקש **APP_PASSWORD** — הסיסמה שבה תיכנס למערכת. מפתחות ה-API אפשר להשאיר ריקים ולהדביק מתוך המערכת.
4. **Apply** — הבנייה לוקחת כמה דקות, ומתקבלת כתובת קבועה (`https://ai-production-ap.onrender.com` או דומה).
5. נכנסים עם הסיסמה → **"מפתחות"** בסרגל העליון → מדביקים OpenAI, Anthropic ו-KIE. כל מפתח נבדק לפני שהוא נשמר.

עלות Render: תוכנית Starter (~$7 לחודש) + דיסק קבוע 10GB (~$2.5 לחודש) — הדיסק שומר את הפרויקטים, הקבצים והמפתחות.
בנוסף: OpenAI, Anthropic ו-KIE גובים לפי שימוש (סרטון של 30 שניות עם 8 שוטים: בערך $2–5 ב-KIE).

אבטחה: כל ה-API דורש התחברות (עוגייה חתומה, HttpOnly), ניסיונות כניסה מוגבלים, והשרת מסרב לעלות בלי סיסמה כשהוא פתוח לרשת.

## הפעלה

**ווינדוס — בלחיצה אחת:**
1. פעם ראשונה: לחיצה כפולה על `start-windows.bat` (מתקין, בונה ומפעיל). נוצר אייקון **AI Production AP** על שולחן העבודה.
2. מכאן והלאה: לחיצה על האייקון בשולחן העבודה — השרת עולה ברקע (בלי חלון שחור) והדפדפן נפתח על המערכת.
   אם המערכת כבר רצה, הלחיצה רק פותחת את הדפדפן. לכיבוי: `stop-windows.bat`.
   יומן השרת: `data\server.log`.

**חיבור מפתחות:** בתוך המערכת לוחצים על **"מפתחות"** בסרגל העליון ומדביקים מפתח ל-ChatGPT (OpenAI), Claude (Anthropic)
ו-KIE. כל מפתח נבדק מול הספק (בלי עלות) והתג מתעדכן ל-**"מחובר: ChatGPT ✓ · Claude ✓ · KIE ✓"**.
המפתחות נשמרים רק בשרת (`data/secrets.json`) — לא בדפדפן ולא ב-GitHub.

**מק:** לחיצה כפולה על `start-mac.command`.

> אם הדפדפן מציג `ERR_CONNECTION_REFUSED` — השרת לא רץ. לחץ שוב על האייקון, או בדוק את `data\server.log`.

**ידנית:**

דרישות: Node.js 22.13 ומעלה (משתמש ב-SQLite המובנה של Node — אין צורך בהתקנת מסד נתונים).

```bash
npm install
cp .env.example .env        # ערוך והוסף OPENAI_API_KEY
npm run dev                 # שרת: http://127.0.0.1:3001 · ממשק: http://localhost:5173
```

הרצה "רגילה" (שרת אחד שמגיש גם את הממשק):

```bash
npm run build && npm start  # http://127.0.0.1:3001
```

פקודות נוספות:

| פקודה | מה עושה |
| --- | --- |
| `npm test` | בדיקות ה-Workflow, האישורים, ה-Jobs, שיתוף ChatGPT+Claude, ההפקה המלאה (כולל עריכת ffmpeg) וההתחברות |
| `npm run typecheck` | בדיקת טיפוסים לכל החבילות |
| `npm run seed:demo` | יוצר פרויקט הדגמה מסומן `[DEMO]` (ללא AI, ללא עלות) |

הנתונים נשמרים ב-`data/production.db` וקבצים שהועלו ב-`data/uploads/` (התיקייה לא נשמרת ב-Git). רענון הדפדפן או הפעלה מחדש של השרת לא מוחקים דבר.

## גרסת claude.ai (דף בלי שרת — Claude בלבד)

המערכת זמינה גם כעמוד ב-claude.ai — נפתחת בלחיצה, בלי שרת מקומי ובלי מפתח API:
https://claude.ai/artifact/FP2M7HTzSYeEbhH8UJoWTD

- **AI:** תסריטים וסטורי בורד נכתבים ב-Claude דרך חשבון claude.ai של מי שפותח (בשימוש הראשון מופיעה בקשת אישור). אותם פרומפטים ואותה ולידציה כמו בגרסה המקומית.
- **נתונים:** כל לוגיקת ה-workflow של השרת רצה בדפדפן מעל SQLite (sql.js). המסד נשמר בענן כמסמכים פרטיים למשתמש (`data/users/<id>`) — גם בעל העמוד לא רואה אותם.
- **קבצים:** רפרנסים וקבצי בריף נשמרים באחסון הנכסים של העמוד (עד 20MB לקובץ).
- **ההבדלים מגרסת השרת:** אין ChatGPT ואין הפקת מדיה (KIE/ffmpeg) — רק אפיון, תסריט וסטורי בורד. אין לפתוח את המערכת בשני חלונות במקביל — חלון שני מזהה זאת ועוצר שמירה כדי לא לדרוס.

בנייה מחדש: `npm run build:cloud` → `web/dist-cloud/ai-production-ap.html` (קוד: `web/src/cloud/`, הגדרות: `web/vite.cloud.config.ts`).

## הגדרת מפתחות API

כל המפתחות נשמרים **רק בשרת**, בקובץ `.env` (שמוחרג מ-Git). הממשק לא רואה אותם.

| משתנה | חובה? | הסבר |
| --- | --- | --- |
| `OPENAI_API_KEY` | לא (עדיף לחבר מתוך המערכת) | מפתח מ-[platform.openai.com/api-keys](https://platform.openai.com/api-keys). **מנוי ChatGPT לא כולל גישת API** — נדרש חשבון API עם קרדיט. |
| `OPENAI_MODEL` | לא | ברירת מחדל `gpt-4.1`. ניתן לדרוס לכל פרויקט במסך ההגדרות. המודל חייב לתמוך ב-Structured Outputs. |
| `ANTHROPIC_API_KEY` | לא (עדיף לחבר מתוך המערכת) | מפתח מ-[platform.claude.com](https://platform.claude.com/settings/keys). Claude מבקר ומשפר כל טיוטה. |
| `ANTHROPIC_MODEL` | לא | ברירת מחדל `claude-opus-5-5`. |
| `KIE_API_KEY` | לא (עדיף לחבר מתוך המערכת) | מפתח מ-[kie.ai](https://kie.ai/api-key) — תמונות, וידאו, קריינות ומוזיקה. |
| `APP_PASSWORD` | **חובה בענן** | סיסמת הכניסה. בלעדיה השרת לא עולה כשהוא פתוח לרשת. |
| `JOB_CONCURRENCY` | לא | כמה יצירות רצות במקביל (ברירת מחדל 4). |
| `OWNER_NAME` | לא | השם שנרשם באישורים ובהיסטוריה. |
| `HOST` / `PORT` | לא | ברירת מחדל `127.0.0.1:3001` (נגיש רק מהמחשב המקומי). |

בלי מפתח: משימת ה-AI נכשלת מיד עם הסבר, השלב מסומן **חסום**, ונשלחת התראה. ניתן:
- להוסיף מפתח, להפעיל מחדש את השרת וללחוץ "נסה שוב" במסך המשימות, או
- לכתוב את התסריט ידנית, או
- לבחור ספק "הדגמה" בהגדרות הפרויקט (תוכן תבניתי שמסומן `DEMO` בכל מקום — לא תוצר AI).

## המוח של המערכת — ידע ולמידה

שני מקורות ידע נכנסים לכל תסריט וסטורי בורד (לצד האפיון):

- **ספר הידע** — הסקילים שלימדת את Claude (קובצי `SKILL.md`). מעלים אותם במסך "🧠 המוח" או דרך `POST /api/skills/import`.
  Claude מזקק כל סקיל להנחיות הפקה (בלי הוראות הפעלה של כלים) ומסמן תחומים ולקוחות. סקיל של לקוח נכנס רק לפרויקטים שלו;
  נהלי עבודה (`operations`) נשמרים ולא נכנסים לפרומפטים. תסריט מקבל תסריט/אודיו/כללי, סטורי בורד מקבל סטורי בורד/תמונות/אנימציה/כללי.
- **כללים שנלמדו** — כל בקשת תיקון, בקשת שינויים ואישור עם הערה נשמרים לפי לקוח ותחום. כל 3 הערות Claude מעדכן סט כללים קצר
  (כלליים ולכל לקוח). כלל שכיבית לא יחזור.
- **קליעה מהפעם הראשונה** — אחוז התסריטים, השוטים והמדיה שאושרו בלי תיקון, לפי תחום וחודש. כך רואים אם המערכת משתפרת.

## מעקב זמן עבודה

לשונית **⏱ זמן עבודה** בכל פרויקט, ועמודת זמן ו"זמן עבודה השבוע" בדשבורד:

- **טיימר** — כפתור "התחל טיימר" בכותרת הפרויקט (נרשם על השלב הנוכחי). רץ טיימר אחד בכל רגע; הפעלה בפרויקט אחר עוצרת את הקודם. הטיימר מוצג בסרגל העליון בכל מסך ושורד רענון/סגירת דפדפן.
- **הזנה ידנית** — לעבודה מחוץ למערכת (Higgsfield, עריכה, שיחות לקוח). ניתן לערוך משך, שלב והערה או למחוק.
- **הערכה אוטומטית** — זמן פעילות במערכת לפי הפעולות שלך (פעולות במרווח ≤20 דק' = סשן). מוצגת בנפרד ומסומנת כהערכה; לא כוללת עבודה בכלים חיצוניים.
- טיימר שרץ מעל `TIMER_MAX_HOURS` (ברירת מחדל 10) שולח התראה שאולי נשכח.

## זרימת העבודה

1. **פרויקט חדש** ← מילוי האפיון. שדות חובה חסרים מסומנים, והכפתור "האפיון הושלם" נעול עד שכולם מולאו.
2. סימון האפיון כמוכן יוצר Event, שמפעיל Job לכתיבת תסריט (OpenAI, פלט JSON מובנה: סצנות, קריינות, משך, פעולה חזותית ותפקיד בסיפור).
3. הטיוטה מוצגת לבדיקה. אפשר לערוך (כל עריכה = גרסה חדשה), להשוות גרסאות, להוסיף הערות, או לבקש מה-AI גרסה מתוקנת לפי משוב.
4. **אישור פנימי** ← הצגה ללקוח ← **סימון אישור לקוח** (מי אישר, מתי ובאיזה ערוץ).
5. אישור הלקוח מפעיל יצירת סטורי בורד: שוט לכל פריט, עם כל שדות הצילום ופרומפטים לתמונה ולהנפשה, ומודל מומלץ (Kling או Seedance עם נימוק).
6. בדיקה ואישור של כל שוט, או בקשת תיקון ← **אישור הסטורי בורד**.
7. רפרנסים לכל שוט: חיפוש בקישור (Pinterest / Unsplash / Pexels בלשונית חדשה), הדבקת קישור מקור, סימון אימות (ברירת מחדל: *לא מאומת*), ציונים, אישור או פסילה.

בכל רגע: הדשבורד מציג מה הושלם, מה רץ, מה ממתין לך, מה חסום ומה הפעולה הבאה.

## עיצוב ומיתוג

השפה העיצובית נגזרת מאתר הסטודיו (Ohad Alfi · AI Production Studio): סימן המותג (טבעת + Play + i) וחתימת "Ohad Alfi",
גרדיאנט holo טורקיז→סגול, ופונטים Assistant (עברית), Poppins (לטינית) ו-Sacramento (לוגו) — מוגשים מקומית, בלי תלות באינטרנט.

- **ערכה כהה** (ברירת המחדל של המותג) ו**ערכה בהירה** — כפתור בסרגל העליון מחליף: לפי המערכת → בהירה → כהה. הבחירה נשמרת בדפדפן.
- כל הצבעים מוגדרים כמשתנים (tokens) בראש `web/src/styles.css` — שינוי מותג נעשה במקום אחד.
